# arXiv-math-0511460

Title: Group-theoretic Algorithms for Matrix Multiplication
Year: 2005

### Cohn-Kleinberg-Szegedy-Umans Theorem 5.5 (STPP and omega)

The simultaneous TPP (STPP) generalization: families of disjoint TPP triples in a group can be combined to yield better omega bounds. If a group H simultaneously realizes <a_1,b_1,c_1>,...,<a_n,b_n,c_n> with character degrees {d_k}, then sum_{i=1}^{n} (a_i b_i c_i)^{omega/3} <= sum_k d_k^omega.

### CKSU Theorem 6.6 + Theorem 3.3 (omega < 2.41 via chart-USPs)

Achieves omega < 2.41 by combining the chart-USP framework (Theorem 6.6) with the Coppersmith-Winograd USP capacity result (Theorem 3.3, USP capacity = 3/2^{2/3}). The construction embeds local USPs into an abelian group via charts, then applies the STPP machinery. The first nontrivial omega bound from the CU approach was omega < 2.9088 (Section 2, using a simpler wreath product).
