# arXiv 2410.14905

Title: Finite matrix multiplication algorithms from infinite groups
Year: 2024

### Lie group framework for MM algorithms

Uses infinite groups (specifically classical Lie groups such as GL_n, U_n, SU_{n/2,n/2}) together with separating functions, border rank, and invariant theory to construct finite MM algorithms. This opens a new direction beyond the finite-group sieve, but the representation-theoretic invariants (irreducible representation dimensions, separating polynomial degrees) remain the key parameters.
