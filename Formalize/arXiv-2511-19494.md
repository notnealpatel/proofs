# arXiv 2511.19494

Title: Probabilistic Bounds on the Number of Elements to Generate Finite Nilpotent Groups and Their Applications
Year: 2025

### Theorem 1 (Rank-chain length relationship for solvable groups)

For a finite solvable group G, len(G) >= rank(G), with equality when G is an elementary abelian p-group. Relevant because the minimal generating set size constrains the structure of subgroups available for TPP triples.

### Theorem 3 (Bounds for generating finite nilpotent groups)

Nearly tight probabilistic bounds on the number of random elements needed to generate a finite nilpotent group: phi_k(G) >= 1-epsilon if k >= rank(G) + ceil(log2(2/epsilon)) or k >= len(G) + ceil(log2(1/epsilon)). Relevant for understanding the subgroup lattice of nilpotent groups examined by the sieve.
