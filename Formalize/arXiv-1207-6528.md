# arXiv 1207.6528

Title: Fast matrix multiplication using coherent configurations
Year: 2013

### Cohn-Umans constructions for omega via wreath products

The wreath product construction is key to IDEA.md: Theorem 7.1 of CKSU05 shows that if a base group H has STPP triples meeting the packing bound, wreath products H wr S_n (i.e., S_n ltimes H^n) can yield omega = 2. The sieve identifies base groups H with the best pseudo-exponent for wreath amplification.
