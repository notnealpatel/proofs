# arXiv 0709.1223

Title: Group-theoretic Methods for Bounding the Exponent of Matrix Multiplication
Year: 2007

### Murthy Theorem 4.13 (TPP subsets realize matrix multiplication)

Murthy's thesis formalizes the Cohn-Umans embedding: if subsets S, T, U of a finite group G satisfy the TPP, then multiplication of |S| x |T| by |T| x |U| matrices can be computed via convolution in the group algebra CG. The resulting inequality z'(G)^{omega/3} <= D_omega(G) (equivalently, |G|^{omega/alpha(G)} <= D_omega(G), proved as Theorem 4.23 using Theorem 4.13) is the foundational link between TPP capacity and the MM exponent. Theorem 4.13 (whose proof constructs explicit embedding/extraction maps in the group algebra) combined with the Wedderburn decomposition (Corollary 4.14) are the starting point for any formalization of the group sieve framework.

### Murthy Corollary 4.4 (Abelian groups give trivial TPP capacity)

For an abelian group G, the triple product map (s,t,u) -> stu is injective (Lemma 4.3), hence |S||T||U| <= |G| for any TPP triple (Corollary 4.4). This is the Cohn-Umans abelian barrier restated: abelian groups cannot beat omega = 3 via the group-theoretic approach. The formalization is the base case that motivates the entire search over nonabelian groups.
