# arXiv 2605.02071

Title: Higher Commutativity in Finite Groups: Exact Asymptotics and Finite Spectrum
Authors: Vadim E. Levit, Robert Shwartz
Year: 2026

### Levit--Shwartz Proposition 2.5 (Isoclinism invariance of higher commuting probabilities)

The r-th higher commuting probability P_r(G) = |{(g_1,...,g_r) : g_i g_j = g_j g_i for all i,j}| / |G|^r is an isoclinism invariant. This extends the classical Pr(G) = P_2(G) invariance and provides a sequence of invariants (P_2, P_3, P_4, ...) that the sieve can compute.

### Levit--Shwartz Proposition 2.6 (Maximal and maximum abelian subgroups under isoclinism)

The maximum order of abelian subgroups is preserved (up to a factor involving the center) under isoclinism. This connects the sieve's abelian-subgroup-search to isoclinism classes.

### Levit--Shwartz Proposition 2.7 (Maximum-order abelian subgroups and higher commuting probabilities: the sharp intersection case)

For groups where every pair of maximum-order abelian subgroups intersects in Z(G), the bounds (N_max(G) * m(G)^r - (N_max(G)-1) * |Z(G)|^r) / |G|^r <= P_r(G) <= M(G) * m(G)^r / |G|^r hold, where M(G) is the number of maximal abelian subgroups. This sandwiches P_r between the maximum abelian subgroup geometry from above and below.

### Levit--Shwartz Corollary 2.8 (Extraspecial p-groups: maximum-order abelian incidence bounds P_r)

For extraspecial groups of order p^{1+2n}: m(G) = p^{n+1}, N_max(G) = M(G) = prod_{i=1}^{n}(p^i + 1), and (N_max(G) * p^{(n+1)r} - C(N_max(G),2) * p^{nr}) / p^{(2n+1)r} <= P_r(G) <= N_max(G) * p^{(n+1)r} / p^{(2n+1)r}. In particular P_r(G) = N_max(G) * p^{-nr} + O(p^{-(n+1)r}) as r -> infinity.

### Levit--Shwartz Proposition 2.9 (Monotonicity under quotients)

P_r(G/N) >= P_r(G) for any normal subgroup N. Passing to a quotient can only increase the probability that r random elements commute.

### Levit--Shwartz Proposition 2.11 (Monotonicity in r)

P_{r+1}(G) <= P_r(G) for all r >= 2. The sequence P_2, P_3, ... is monotonically decreasing. Moreover, if G is non-abelian, the inequality is strict for all r >= 2.

### Levit--Shwartz Proposition 2.13 (Direct products)

P_r(G x H) = P_r(G) * P_r(H). Multiplicativity across direct products.

### Levit--Shwartz Proposition 2.14 (Submultiplicativity across indices)

P_{n+m}(G) <= P_n(G) * P_m(G). Equivalently, -log P_r(G) is superadditive. Moreover, if G is non-abelian then the inequality is strict.

### Levit--Shwartz Theorem 3.4 (Burnside orbit lemma normalization)

kappa_r(G) = |G|^r * P_{r+1}(G), equivalently P_{r+1}(G) = kappa_r(G) / |G|^r. In particular, |G|^r * P_{r+1}(G) is always an integer. Here kappa_r(G) = |Hom(Z^r, G) / G| is the number of diagonal conjugacy orbits of commuting r-tuples.

### Levit--Shwartz Theorem 4.1 (Dominant abelian asymptotic)

For any finite group G, |Hom(Z^r, G)| = N_max(G) * m(G)^r + O(b(G)^r), equivalently P_r(G) = N_max(G) * (m(G)/|G|)^r + O((b(G)/|G|)^r), where m(G) is the maximum order of an abelian subgroup, N_max(G) is the number of abelian subgroups of that order, and b(G) < m(G) is the second-largest abelian subgroup order. Hence lim P_r(G)^{1/r} = m(G)/|G|.

### Levit--Shwartz Theorem 4.4 (Abelian split quotients: exact tuple count)

For G = A rtimes K with A and K finite abelian, |Hom(Z^r, G)| = sum_{B <= K} lambda(B) * |C_A(B)|^r * phi_r(B), where phi_r(B) counts generating r-tuples of B and lambda(B) counts abelian lifts of B with full kernel C_A(B). The coprimality condition (|A|, |K|) = 1 is not required for this formula; it is a separate result (Theorem 4.5) that in the coprime case lambda(B) = |A : C_A(B)|.

### Levit--Shwartz Theorem 4.18 (Finite Dirichlet spectrum and pole expansion)

For non-abelian G, P_r(G) = sum_{m >= 2} c_m(G) / m^r where only finitely many c_m(G) are nonzero. Equivalently, the rank-generating series P_G(z) = sum_{r >= 2} P_r(G) z^{r-2} = sum_{m >= 2} c_m(G) / (m(m-z)) is rational with finitely many poles at indices m = |G:A| for abelian subgroups A. The first pole is at z = |G|/m(G) with residue coefficient N_max(G) * m(G) / |G|.

### Levit--Shwartz Corollary 4.21 (Linear recurrence, Hankel rank, and finite determination)

The sequence (P_r(G))_{r >= 2} satisfies a linear recurrence of minimal order t = |{m >= 2 : c_m(G) != 0}|, equivalently the infinite Hankel matrix (P_{i+j+2}(G))_{i,j >= 0} has rank t. The initial block P_2(G), ..., P_{2t+1}(G) determines the entire hierarchy.

### Levit--Shwartz Corollary 4.22 (Inverse finite-spectrum rigidity)

If P_r(G) = P_r(H) for infinitely many r >= 2, then c_m(G) = c_m(H) for all m >= 2, hence the full Dirichlet spectra coincide (P_G(z) = P_H(z)). In particular m(G)/|G| = m(H)/|H| and N_max(G) = N_max(H). If moreover |G| = |H|, then kappa_r(G) = kappa_r(H) for all r >= 1.
