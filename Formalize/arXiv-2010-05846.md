# arXiv 2010.05846

Title: A Refined Laser Method and Faster Matrix Multiplication
Year: 2020

### Alman-Vassilevska Williams Main Result (omega < 2.37286)

The bound omega < 2.3728596, obtained by a refined laser method (Theorem 4.1) applied to CW_5^{otimes 32}. The group-theoretic framework captures this bound, and the sieve aims to discover structures that could eventually surpass it.
