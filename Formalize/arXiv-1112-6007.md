# arXiv 1112.6007

Title: New lower bounds for the border rank of matrix multiplication
Year: 2011

### Landsberg-Ottaviani Theorem 1.1 / Corollary 1.2 (Border rank lower bound for matrix multiplication)

Theorem 1.1: For n <= m and all l >= 1, border_rank(M_{m,n,l}) >= n*l*(n+m-1)/m. Corollary 1.2: border_rank(M_{n,n,l}) >= 2nl - l, and in particular border_rank(M_n) >= 2n^2 - n. For 3x3 matrices, 15 <= border_rank(M_{3,3,3}) <= 21. The bounds come from new equations (minors of a Young flattening map) that bilinear maps of small border rank must satisfy but matrix multiplication fails to satisfy.
