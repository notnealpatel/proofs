# Bari-kashthesis

Title: On the Structure Tensor of sl_n
Author: Kashif Karim Bari
Year: 2021

### Rank and border rank bounds for the structure tensor of sl_n

The thesis applies Koszul flattenings, border substitution, and border apolarity to bound the rank and border rank of the structure tensor T_{sl_n}. The main results are:

- Theorem 18: \underline{R}(T_{sl_4}) >= 28, obtained via Koszul flattenings combined with border substitution.
- Theorem 19: \underline{R}(T_{sl_3}) >= 16, obtained via border apolarity. This is the first example of an explicit tensor in C^m x C^m x C^m with border rank at least 2m for m < 13.
- Theorem 20: R(T_{sl_3}) <= 20, obtained via a numerical rank decomposition found using Newton's method and the LLL algorithm.
