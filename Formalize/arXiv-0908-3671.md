# arXiv 0908.3671

Title: A Short Note on Disjointness Conditions for Triples of Group Subsets Satisfying the Triple Product Property
Year: 2009

### Murthy Section 1.2 (Minimal disjointness for TPP triples)

If (S, T, U) is a TPP triple in G, then any two of S, T, U intersect in at most one element. This establishes the nine disjointness cases for TPP triples, classified by the disjointness type number w = 0, 1, 2, or 3. Formalizing this gives the combinatorial backbone for enumerating TPP triples.

### Murthy Section 1.3 (Additive size bounds for maximal TPP triples)

For a maximal TPP triple (S, T, U) of G with |G| = n: 3 * n^{1/3} <= |S| + |T| + |U| <= n + 3. This is a basic necessary condition that constrains the search space and is used in the group sieve's tier-based elimination.
