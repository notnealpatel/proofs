# arXiv 1305.0448

Title: A Fast Search Algorithm for (m,m,m) Triple Product Property Triples and an Application for 5x5 Matrix Multiplication
Year: 2013

### Hart-Hedtke-Mueller-Hannemann-Murthy (fast TPP search for 5x5)

Efficient search algorithms for finding large TPP triples, applied to finding triples suitable for 5x5 matrix multiplication. The algorithmic results inform what is computationally feasible for the sieve.
