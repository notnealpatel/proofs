# arXiv 1812.06952

Title: Barriers for fast matrix multiplication from irreversibility
Year: 2018

### Christandl-Vrana-Zuiddam Theorem 3.1 (Irreversibility barrier)

For any tensor t, the upper bound on omega obtained via an intermediate tensor t satisfies omega(<2>, t) * omega(t, <2,2,2>) >= 2 * irr(t). In particular, any approach using an irreversible tensor (irr(t) > 1) as an intermediate step cannot prove omega = 2. The barrier applies to any tensor, not only the Coppersmith-Winograd family, and monomial versions (Theorems 3.4--3.5, Corollary 3.6) extend it to the group-theoretic approach.
