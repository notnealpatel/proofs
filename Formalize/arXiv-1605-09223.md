# arXiv 1605.09223

Title: On large subsets of F_q^n with no three-term arithmetic progression
Year: 2016

### Ellenberg-Gijswijt Theorem (Cap set bound)

If A is a subset of (Z/3Z)^n containing no three-term arithmetic progression, then |A| = o(2.756^n). While not directly about groups and MM, this polynomial method result underlies the STPP barrier for abelian groups of bounded exponent, which is the negative result that motivates the search over nonabelian groups.
