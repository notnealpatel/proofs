# arXiv 1107.5969

Title: A note on the Triple Product Property subgroup capacity of finite groups
Year: 2011

### Hedtke Theorem (Improved upper bound h(G) for subgroup TPP capacity)

The bound h(G) = max{b(G), |G|} where b(G) = max_{4 <= i <= N} min{|S_i| * |G| / |Core_G(S_i)|, |S_i| * Delta(S_i)}, with N = max{i : |S_i| <= |G|/(|S_3|+|S_2|-1)} and Delta(S_i) = max{|S_j|*|S_k| : 1 < k < j < i, |S_i|(|S_j|+|S_k|-1) <= |G|}. Then beta_g(G) <= h(G). This improves Neumann's bound t(G) since beta_g <= h <= t, and determines which groups cannot yield nontrivial omega bounds via subgroups.
