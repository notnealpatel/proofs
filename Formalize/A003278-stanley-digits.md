  A003278 = Stanley sequence: greedy increasing
  sequence from 1, 2 avoiding any 3-term arithmetic
  progression. Classical fact (unformalized anywhere):
  A003278 = numbers whose base-3 representation of
  n-1 uses only digits 0 and 1 (offset convention per
  entry). Conjectured identities:
    A003278(n) = (A191107(n) + 2)/3
               = (A055246(n) + 5)/6
    A191107(n) = A003278(2n - 1)          (Bos)
  where A191107 is generated by x -> 3x-2, 3x+1 from
  1, and A055246 by the Cantor middle-third erasure
  intervals.
