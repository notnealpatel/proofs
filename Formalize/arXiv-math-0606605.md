# arXiv-math-0606605

Title: A new algorithm for finding the nilpotency class of a finite p-group describing the upper central series
Authors: Maria A. Avino-Diaz
Year: 2006

### Avino-Diaz's algorithm for nilpotency class of Delta(G)

An algorithm for computing the nilpotency class and upper central series of the maximal normal p-subgroup Delta(G) of the automorphism group Aut(G) of a bounded abelian p-group G, using the upper annihilating sequence of the Jacobson radical. The algorithm is proved to work for p >= 3, and also for p = 2 when sigma(G) >= 2 or when r_s > 1 and s >= 2 (Theorem 5.3). The nilpotency class depends only on the exponents (n_1, ..., n_s) and the rank r_s of the last homocyclic component.
