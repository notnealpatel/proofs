# arXiv 1401.7714

Title: Powers of Tensors and Fast Matrix Multiplication
Year: 2014

### Le Gall Table 1 (omega < 2.3728639)

The record-holding bound on omega at time of publication, obtained by analyzing the 32nd tensor power of the Coppersmith-Winograd tensor using convex optimization (Algorithm A) applied to the 2nd and 4th powers of the 8th tensor power (whose component values were computed via non-convex Algorithm B). The sieve aims to discover structures that could improve it.
