# arXiv 2602.15796

Title: On the triple product property for subgroups of finite nilpotent groups of class 2
Year: 2026

### Murthy Theorem 3.1 (rho_0 < sqrt(|G:Z(G)|) for class 2 groups)

For any group G of nilpotency class 2, rho_0(G) < sqrt(|G:Z(G)|). This is the central bound for class-2 groups: it ties subgroup TPP capacity directly to the central index, which the sieve computes. Since |G:Z(G)| is computable from the character table, this gives an effective upper bound.

### Murthy Theorem 4.1 (rho_0 <= p for p-groups with cyclic G' of order p)

If G is a nonabelian p-group with cyclic commutator subgroup G' of order p, then rho_0(G) <= p. This covers all extraspecial groups. Since extraspecial p-groups are the simplest class-2 p-groups, this result establishes the baseline for the sieve's analysis.

### Murthy Corollary 4.2 (Extraspecial groups: rho_0 <= p)

For an extraspecial group of order p^{1+2n}, rho_0(G) <= p. This is a direct consequence of Theorem 4.1 applied to groups with |G'| = p and Z(G) = G'.

### Murthy Theorem 5.1 (rho_0 = 1 for class-2 p-groups with large center)

If G is a p-group of nilpotency class 2 with p^2 <= |G:Z(G)| <= p^3, then rho_0(G) = 1. These "large center" groups are killed by the sieve.

### Murthy Theorem 6.1 (rho_0 = 1 for class-2 p-groups with cd(G) = {1, p})

If G is a p-group of nilpotency class 2 with character degree set cd(G) = {1, p}, then rho_0(G) = 1. The p^2 in cd(G) survival criterion from IDEA.md: groups with only degrees 1 and p have trivial subgroup TPP capacity.

### Murthy Proposition 2.7 (TPP split for subgroups in shared subgroup)

If (S, T, U) is a TPP triple with S, T contained in a subgroup H, then |S||T||U|/|G| <= rho(H). Additionally, if (S, T, U) is maximal for G and H is abelian, then rho(G) = 1. This is the subgroup-splitting lemma that constrains which triples can be nontrivial.

### Murthy Lemma 2.10 (Quotient by normal subgroup preserves or improves rho_0)

If N is normal in G and N <= S for a maximal subgroup TPP triple (S,T,U), then rho_0(G/N) >= rho_0(G). The sieve can reduce to quotients.

### Murthy Proposition 2.14 (rho_0 = 1 for p-groups of order <= p^4)

All p-groups of order at most p^4 have trivial subgroup TPP capacity. This is the base case for the sieve's tier-0 elimination.
