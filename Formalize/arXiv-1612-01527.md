# arXiv 1612.01527

Title: Matrix multiplication algorithms from group orbits
Year: 2016

### Grochow-Moore (Group orbit approach to MM algorithms)

Constructs matrix multiplication algorithms from orbits of finite groups acting on tensors by conjugation, using representation theory to derive constraints on the decomposition. Recovers Strassen's algorithm in a symmetric form and gives new algorithms for n=3,4,5, all achieving tensor rank n^3 - n + 1 via a lattice-based construction.
