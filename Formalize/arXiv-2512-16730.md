# arXiv 2512.16730

Title: A note on the triple product property for finite groups with abelian normal subgroups of prime index
Year: 2025

### Murthy Theorem 4.1 (rho_0 bound for abelian-normal-of-prime-index)

If G has an abelian normal subgroup of prime index p, then rho_0(G) <= p^2/(2p-1). This is the sharpest known bound on subgroup TPP ratio for this structural class. For p = 2 (dihedral groups, etc.), rho_0 <= 4/3. This result is central to the group sieve: it eliminates many groups from having nontrivial subgroup TPP capacity.

### Murthy Corollary 4.3 (p-groups with abelian subgroup of index p have rho_0 = 1)

If G is a p-group with an abelian subgroup of index p then rho_0(G) = 1. This kills all p-groups with maximal abelian subgroups for the subgroup TPP approach.

### Murthy Conjecture 5.1 (rho <= p^2/(2p-1) for cyclic-normal-prime-index)

Conjecture: if G has a cyclic normal subgroup of prime index p, then rho(G) <= p^2/(2p-1). This extends the proven subgroup result to arbitrary TPP triples. The first untested case at order 64 for p=2 is identified in IDEA.md as a target for the sieve.

### Murthy Lemma 3.3 (Coset decomposition for subgroup TPP triples)

Technical lemma: if H is abelian normal and (S,T,U) is a subgroup TPP triple, then (1) for each xH in the common H-support of S and T, the set S_x^{-1} T_x U_0 is a coset of S_0 T_0 U_0 in H, non-trivial when xH is non-trivial; (2) if additionally U_0 is normal in G, distinct cosets xH, yH yield distinct cosets S_x^{-1} T_x U_0 and S_y^{-1} T_y U_0; (3) the "mixed" cosets S_x^{-1} T_x U_0 and S_y^{-1} U_y T_0 are always distinct when at least one of xH, yH is non-trivial. This coset-counting argument is the engine of the proof of Theorem 4.1.
