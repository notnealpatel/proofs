## P5 (postdoc) — Erdős–Rado sunflower bound
(new file `Proofs/Erdos/Erdos20/ErdosRado.lean`)

**Goal.** Prove the classical Erdős–Rado sunflower lemma on the
directory's existing defs: a family of k-sets with more than
(r−1)^k · k! members contains a sunflower with r petals.

Existing layer (verified 2026-08-05, all sorry-free):
`Erdos/Erdos20/Sunflower.lean` has

```lean
def IsSunflowerWith (sub : Finset (Finset (Fin n))) (K : Finset (Fin n)) : Prop :=
  (∀ S ∈ sub, K ⊆ S) ∧ (∀ S ∈ sub, S \ K ≠ ∅) ∧
  (∀ S ∈ sub, ∀ T ∈ sub, S ≠ T → S ∩ T = K)

def HasSunflower (family : Finset (Finset (Fin n))) (k : ℕ) : Prop := ...
```

plus compression machinery (franklShift, matchingNumber, shadow
ladders). The headline bound is NOT stated anywhere in the directory
(SpreadLemma.lean says so in a comment). CAUTION: `IsSunflowerWith`
requires nonempty petals (`S \ K ≠ ∅`) — check how the classical
induction interacts with that clause (the standard proof's base case
and the "all sets share a kernel element" branch); if the convention
forces an off-by-one against the textbook bound, prove the bound the
convention supports and disclose the delta.

Model: Isabelle AFP entry "Sunflowers" (René Thiemann) — proves
exactly this bound. The standard proof is induction on k via maximal
disjoint subfamilies. Decide whether the ground type `Fin n` is

prefer whatever lets the existing defs be reused without surgery.

Novelty framing for the header: AFP has this in Isabelle; Mathlib has
no sunflower content; this is a first-in-Lean candidate, NOT a
first-formalization. Do not confuse with Naslund–Sawin (#857) — a
different theorem.
