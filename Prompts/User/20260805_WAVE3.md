## P9 (postdoc) — Melfi 1996: even = practical + practical
(new file `Proofs/Enumerative/MelfiPracticalSum.lean`)

**Source:** NEXT_TARGETS P1 flagship. Melfi, "On two conjectures about
practical numbers", J. Number Theory 56 (1996) 205–210.

**Goal.** Prove that every even positive integer is the sum of two
practical numbers. This is a 6-page constructive proof using Stewart's
criterion and a bounded-ratio practical sequence. The existing
`StewartCriterion.lean` (697 lines, sorry-free) and `Practical.lean`
carry the prerequisites.

**Downstream value.** Discharges the `melfi` sorry inside three sketch
files (`A005153Switkay`, `A222603PracticalTree`, `A373686SomuTran`).

Fetch the paper. Read `StewartCriterion.lean` and `Practical.lean`
before planning the proof. The brief's "L risk" note in NEXT_TARGETS
refers to the twin-practical ratio argument — assess it honestly.

## P10 (postdoc) — Kummer digit layer (Erdős #376)
(new file `Proofs/Erdos/Erdos175/KummerDigits.lean`)

**Source:** NEXT_TARGETS P2. Erdős #376 + the BINOM family.

**Goal.** Prove Kummer's theorem: `padicValNat p (Nat.choose (m+n) m) =`

layer, not the $1000 headline.

**Downstream value.** Unlocks #175 remainder, #699, #1093–#1095, #406 —
five problems depend on this layer. The sketch
`Proofs/Scratch/ErdosCandidates/E376.lean` has the statement shape.
