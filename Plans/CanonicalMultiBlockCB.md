# Canonical multi-block CB: a carry-aware variable-block argument

## Proposition and scope

Let

```
Z = sum_{j<b} r^(s_j) Z_j,       s_j=sum_{t<j} ell_t,
ell_j=k_j+h_j,
Z_j=A_j+r^k_j V_j,               A_j=sum_{i<k_j} U_{j,i}r^i.
```

Let `b>=1`, `r>=2`, and `k_j,h_j>=1`.  Let every integer
`a_{j,i}>=2` satisfy `2 max_i a_{j,i}-1<=r`.  The vectors `U_j` are
arbitrary laws supported on `product_{i<k_j}[0,a_{j,i})`; each `V_j` is
uniform on `[0,r^h_j)`, independent of `U_j` and of every other block.  All
logs and finite entropies below are natural.  Write
`delta_j=sum_i log a_{j,i}-H(U_j)` and assume

```
delta_j <= 7 k_j/192,
Delta_j := k_j log r-sum_i log a_{j,i}+delta_j
             <= 7 ell_j/192.
```

The blocks are mutually independent.  Thus the stated individual canonical
bounds imply `sum_j Delta_j <= 7L/192`; we record the latter only as the
convenient global-height consequence.  Let `Z'` always denote an independent
copy of `Z`, and define

```
g_Z(n) := H(Z-nZ')-H(Z).
```

The intended conclusion is that one absolute `C` satisfies, for every nonzero integer
polynomial `P` of degree `d` and coefficient `l1` norm `S>=1`,

```
g_Z(P(r)) <= C [d+1+log(1+S)] max(g_Z(1),g_Z(r)).       (MCB)
```

This note gives a prose proof from three entropy estimates.  It remains a
mathematical argument, not Lean-certified, and does not assert full CB,
`#711`, rational functional calculus, or any SC/inverse statement.

## 1. The unshifted reference has no block-boundary loss

For block `j`, put `q_j=r^k_j`, `R_j=r^h_j`,
`B_j=A_j-A'_j`, and `X_j=V_j-V'_j`.  In the scalar subtraction of two
canonical concatenations, process block `j` with incoming carry `C_j`:

```
B_j+C_j = D_j + q_j C'_j,       0 <= D_j < q_j.
```

The lower coefficient widths imply that the evaluation map for `B_j` is
injective: successive reduction modulo `r` recovers all lower coefficients.
In particular `B_j` is supported in an interval of width at most `q_j-1`,
so reduction modulo `q_j` is injective on its support and
`H(B_j mod q_j)=H(B_j)`.

Let `H_j` be the sigma-field generated by the output digits in blocks
`0,...,j-1`.  The precise independence statement is the conditional factorization: for
all admissible values,

```
Pr(B_j=b,X_j=x,C_j=c | H_j=h)
 = Pr(B_j=b,X_j=x) Pr(C_j=c | H_j=h).
```

Equivalently, the current pair `(B_j,X_j)` is jointly independent of
`(C_j,H_j)`.  In particular `C_j` is not claimed to be `H_j`-measurable.  Write

```
D_j=(B_j+C_j) mod q_j,
T_j=(X_j+floor((B_j+C_j)/q_j)) mod R_j.
```

For each admissible value `H_j=h`, the conditional law of `D_j` is a
mixture, over `C_j`, of cyclic translates of the law of `B_j mod q_j`.
Thus cyclic entropy concavity gives

```
H(D_j | H_j) >= H(B_j).
```

Now sum over the hidden carry rather than conditioning on it.  Because
`X_j mod R_j` is uniform and independent of `(B_j,C_j,H_j)`,

```
H(T_j | H_j,D_j) = log R_j.
```

Therefore the actual chain rule is

```
H(D_j,T_j | H_j)
 = H(D_j | H_j)+H(T_j | H_j,D_j)
 >= H(B_j)+log R_j.
```

The final signed carry contributes nonnegative entropy.  Summing this chain
over blocks gives

```
H(Z-Z') >= sum_j [H(A_j-A'_j)+log R_j].
```

Subtracting `H(Z)=sum_j[H(A_j)+log R_j]` proves

```
g_Z(1) >= sum_j G1_j,
G1_j := H(A_j-A'_j)-H(A_j).                             (1)
```

The reviewed correlated-box input gives `G1_j >= 7 k_j/96 - delta_j`
(Plans/CorrelatedPolynomialBox.md, revision `aabb4e8797e157b192395a143c0833519bdfa25a`,
reviewed prose input; the single-block adopted input is revision
`3a2f13836bc3ddb414d4820966b3cf3e47887593`).  Since
`delta_j<=7k_j/192`, this implies `G1_j>=7k_j/192`.  Therefore

```
kappa:=sum_j k_j <= (192/7)g_Z(1),     delta:=sum_j delta_j <= g_Z(1). (2)
```

The canonical-height input is Plans/CanonicalBaseCarryTransfer.md, revision
`47c425bc238381a14ae87407655e145eb0d210f0`, also a reviewed prose input.
The argument does not pay one carry entropy per block: each incoming carry is
independent of the current block at the point where the cyclic entropy
inequality is applied.

## 2. A scalar shifted lemma for arbitrary correlations

Here is the boundary estimate needed for the shifted reference.  Consider any jointly distributed digit vector `X=(X_0,...,X_{L-1})`, with
`X_i` supported on the nominal interval `[0,N_i)`, but with an otherwise
arbitrary (possibly correlated and nonuniform) law.  Put

```
t_i=log N_i,  B=sum_i t_i,
δ=B-H(X),  t_L=0,
E=sum_{i=1}^L (t_(i-1)-t_i)_+ .                         (3)
```

Assume `N_i<=r`, and let `X'` be an independent copy.  Define the scalar
integers

```
A=sum_i X_i r^i,       A'=sum_i X'_i r^i.
```

For the scalar output `A-rA'`, retain all base-`r` residues and the final
signed quotient.  Since each `N_i<=r`, evaluation is injective on the digit
box and `H(A)=H(X)`.  Then

```
g_A(r) := H(A-rA')-H(A) >= E-δ.                        (4)
```

To verify (4), at position `i` the two possible sources are `X_i` and
`X'_(i-1)` (with the absent endpoint omitted).  Select the source with the
larger nominal alphabet, and call the selected collection `Q` and the
unselected collection `R`.  The selection rule is fixed by nominal sizes
(ties use a fixed index), not by realized digit values.  The selected nominal
log-size is

```
M = sum_{i=0}^L max(t_i,t_(i-1)) = B+E,
```
where `t_(-1)=0`.  Condition on `R` and recover `Q` from low to high: the incoming carry is
determined by previously recovered sources, and the current residue has
coefficient `+1` or `-1` on the selected source.  An interval of length at
most `r` is uniquely determined by its residue modulo `r`.  The final signed
quotient recovers the terminal selected source.  Thus `Q` is determined by
`(A-rA',R)`, and

```
H(A-rA') >= H(Q|R)
 >= 2(B-δ) - (2B-M)
 = B+E-2δ.
```

Subtracting `H(A)=H(X)=B-δ` proves (4).  Independence of the copy is
essential.  The endpoint quotient is essential as well.  The hypothesis
`N_i<=r` is also essential; without it, a single digit of size greater than
`r` defeats residue recovery.

Apply (4) to the full concatenated digit vector, whose nominal alphabets are
the lower `a_{j,i}` and the uniform padding alphabets `r`.  For this vector,
`delta=sum_j delta_j`, and `E` is the sum of all positive drops between
successive nominal log-alphabets, including the final drop to zero.  Hence

```
E <= g_Z(r)+delta <= 2K,   K=max(g_Z(1),g_Z(r)).         (5)
```

The last inequality uses (2).  Notice that this is a scalar statement about
actual digit output; it is not an assertion that formal polynomial
coefficients evaluate injectively.

## 3. Shared polynomial entropy code

Let `P(T)=sum_{t=0}^d p_t T^t` with integer coefficients, `p_d!=0`, and
`S=sum_t |p_t|>=1`.  Let `n=P(r)`.  The case `n=0` is immediate, so
assume `n!=0`.  Let `W(T)`
be the formal polynomial with the `L` concatenated input digits as
coefficients, and form

```
F(T)=W(T)-P(T)W'(T)=sum_i f_i T^i.
```

Normalize formally by

```
f_i+c_i = D_i+r c_(i+1),    c_0=0.
```

Since every source digit is in `[0,r)`, `|f_i| <= (1+S)(r-1)`.  The floor
recurrence maps `[-S-2,S+2]` into itself, so induction gives `|c_i|<=S+2`;
every formal carry has at most `2S+5` values.  These are formal normalization
carries, not scalar multiplication carries.

We now give a deterministic entropy code for the actual scalar output
`Z-nZ'`.  Code all actual base-`r` output digits in every uniform padding
interval.  In each lower block, code the first `min(d,k_j)` actual output
digits.  If a lower suffix remains, code the formal coefficient `f_i` at
each suffix position and code the formal normalization carry immediately
after the explicitly coded prefix, namely the carry entering that suffix.
When `d=0` this is the block-start carry; when `d>=k_j` there is no suffix
and no carry is recorded for that block.  Finally code the signed terminal
quotient.

This code reconstructs the output deterministically.  Indeed, the explicitly
coded prefix handles every cross-block coefficient involving a shift of at
most `d`; after position `d` inside a block, all formal terms `f_i` involve
only source indices in that same block.  The supplied carry is at the suffix
start, so the normalization recurrence reconstructs every suffix output
digit.  Uniform positions are already coded, so no unknown coefficient is
needed to cross a padding interval.  A block-start carry alone would not in
general suffice after an output-coded prefix; this suffix-start datum is
therefore part of the code.

The coefficient range gives, at an uncoded lower position `i`, the finite
integer-range bound

```
H(f_i) <= t_i + log(1+S) + eta_i,
eta_i=max_(0<=t<=d)(t_(i-t)-t_i)_+.
```

Indeed, its support has cardinality at most
`1+(N_i-1)+sum_t |p_t|(N_(i-t)-1)`, which is at most
`(1+S) max_(0<=t<=d)N_(i-t)`; the `1+` is the width-plus-one correction.
Here and below absent indices are omitted.

Let `t_i` be the global nominal logs for `0<=i<L`, put `t_L=0`, and set
`z_p=(t_(p-1)-t_p)_+`, `E=sum_p z_p`.  Partition positions into padding
`H`, lower prefixes `J` of lengths `m_j=min(d,k_j)`, and lower suffixes `I`.
Write `kappa=sum_j k_j`.  For `j>0`, `t_(s_j-1)=log r`, and for `u<m_j`,

```
log r-t_(s_j+u) <= sum_(p=s_j)^(s_j+u) z_p.
```

For the first block use `log r-t_u<=log r+sum_(p=1)^u z_p`.  Each transition
is counted at most `m_j<=d` times and block prefixes are disjoint, so
`sum_(i in J)(log r-t_i)<=dE+d log r`.  For `i in I`, all `i-t` with
`0<=t<=d` lie in the same block and
`eta_i<=sum_(p=i-d+1)^i z_p`; hence `sum_(i in I)eta_i<=dE` (empty when
`d=0`).

There are at most `b<=kappa` suffix carries and `|I|<=kappa`.  The complete
code entropy is at most

```
sum_(i in H union J) log r
 +sum_(i in I)[t_i+log(1+S)+eta_i]
 +b log(2S+5)+H(Q_L),
```

where `Q_L=floor((Z-nZ')/r^L)`.  Since `H(Z)=B-delta`, with `B=sum_i t_i`
and `H union J union I` all positions, subtracting the nominal budget gives

```
g_Z(n) <= |I|log(1+S)+sum_(i in J)(log r-t_i)+sum_(i in I)eta_i
       +b log(2S+5)+delta+H(Q_L).
```

As `0<=Z,Z'<r^L`, `Q_L in [-n,0]` for `n>0` and in `[0,|n|]` for `n<0`.
Thus `H(Q_L)<=log(1+|n|)<=dlog r+log(1+S)`; it is not the formal carry
`c_L`, since a formal polynomial tail may remain.  Using
`log(2S+5)<=3log(1+S)`, we obtain

```
g_Z(P(r)) <= 4kappa log(1+S)+2dE+2dlog r+delta+log(1+S).  (7)
```

This is an entropy upper bound, not a scalar-injectivity assertion.  It uses
formal coefficients only where they are locally decodable and actual output
digits at all uniform or short-prefix interfaces.

## 4. Closing the quantitative estimate

Global padding height gives

```
g_Z(r) >= log r - 7/192,
log r <= 2 g_Z(r) <= 2K,
K >= log 2 - 7/192.
```

Insert (2) and (5) into (7).  With `c0=log 2-7/192>0`, the height input gives
`K>=c0` and `log r<=2K`; hence

```
g_Z(P(r)) <= [(768/7+1/c0) log(1+S)+8d+1] K.
```

This implies (MCB) with an absolute constant, uniformly in arbitrary `b`.
The endpoint checks are explicit: `d=0` makes the interior windows empty;
`d>=k_j` makes block `j` have no suffix; `d>=L` makes every lower block have
no suffix; and `P(r)=0` is immediate.  Negative `n` is covered by the stated
signed range for `Q_L`.  The artifact is author-validated and pending completion of the same
independent artifact review of these changed lines; it is prose-only, not Lean-checked,
and does not claim full CB.

## Valid variable-block examples and limitations

There are admissible nonproduct blocks: take `a=2,r=4,k=20`, let `U_j` be
uniform on the even-parity subset of `{0,1}^20`, and take `h=400`.  Then
`delta_j=log 2`, while
`Delta_j=21 log 2 < 420*7/192`; independent copies may be concatenated for
arbitrarily large `b`, and the total deficit inequality scales linearly.
The proof above is intended to cover this variable-`b` family without a
per-interface loss.

The result remains restricted to the stated narrow lower digits plus uniform
padding.  It does not imply arbitrary full-CB laws, and the scalar shifted
lemma would fail without `N_i<=r`, independent copies, or the terminal signed
quotient.  Formal coefficient bounds, scalar endpoint transfer, and the
single-block correlated-box estimate are prose inputs from the earlier
artifacts, not Lean-checked dependencies.  This note therefore records a
substantial proposed proof mechanism with its exact qualifications rather
than a formal certification or a novelty claim.
